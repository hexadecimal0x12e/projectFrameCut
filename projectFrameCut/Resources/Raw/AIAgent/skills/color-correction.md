## Description

本 Skill 指导你如何调整视频/图片 clip 的颜色参数，包括基础的颜色校正和高级的色轮调色。

## Instructions

### 1. 颜色校正前置步骤

1. 使用 `get_all_clips` 或 `select_clip` 找到目标 clip
2. 使用 `get_propertypanel_visual_tree` 查看 clip 的可调属性
3. 使用 `get_propertypanel_tabs` 查看属性面板标签页，切换到颜色相关的标签页
4. 使用 `get_propertypanel_properties` 获取当前颜色参数

### 2. 基础颜色参数

通过 `set_propertypanel_properties` 调整以下基础参数：

| 属性名 | 说明 | 建议范围 |
|---|---|---|
| `Brightness` | 亮度 | -100 ~ 100（0=原始） |
| `Contrast` | 对比度 | -100 ~ 100（0=原始） |
| `Saturation` | 饱和度 | -100 ~ 100（0=原始） |
| `Hue` | 色相偏移 | -180 ~ 180（0=原始） |
| `Gamma` | Gamma 校正 | 0.1 ~ 5.0（1.0=原始） |
| `Temperature` | 色温 | -100 ~ 100（负=冷色，正=暖色） |
| `Vibrance` | 自然饱和度（保护肤色） | -100 ~ 100（0=原始） |
| `Sharpen` | 锐化 | 0 ~ 100（0=关闭） |
| `Fade` | 褪色/胶片感 | 0 ~ 100（0=关闭） |

### 3. 常用调色方案

#### 自然还原
- 白平衡：调整 Temperature 使画面中性（看肤色是否自然）
- 对比度：+10 ~ +20
- 饱和度：+5 ~ +15
- Vibrance：+10 ~ +20
- 锐化：15 ~ 25

#### 电影感（Cinematic）
- 对比度：+25 ~ +40
- 饱和度：-10 ~ -20（降低饱和度）
- 色温：+5 ~ +10（轻微暖调）
- Fade：5 ~ 15
- 加黑边（上下黑边比例 2.35:1 或 1.85:1）

#### 日系小清新
- 对比度：-10 ~ -5
- 饱和度：+5 ~ +10
- 色温：-10 ~ -5（偏冷）
- 亮度：+5 ~ +10
- 锐化：10 ~ 15

#### 复古/怀旧
- 饱和度：-20 ~ -40
- 色温：+15 ~ +25
- 对比度：+15 ~ +25
- Fade：10 ~ 25

### 4. 调色注意事项

- 每次修改后使用 `get_selected_clip` 或 `get_draft_info` 查看效果
- 建议一次只调整 1-2 个参数，逐步微调
- 自然饱和度（Vibrance）比饱和度（Saturation）更适合人像，因为它保护肤色
- 大幅调整后若效果不佳，可以将参数置零重新开始
